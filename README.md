# Simon Says Game

A classic Simon Says memory game built with HTML, CSS, and JavaScript. Test your memory by repeating the sequence of colors and sounds that Simon gives you!

🔗 **Play the game here:** [https://danielgaudreault.github.io/Simon-says/](https://danielgaudreault.github.io/Simon-says/)

## Features
- **Classic Simon Gameplay:** Follow the sequence of lights and sounds.
- **Increasing Difficulty:** The sequence gets longer as you progress.
- **Responsive Design:** Works on both desktop and mobile devices.
- **Sound Effects:** Authentic sounds for each button press.
- **Score Tracking:** Keep track of your high score.

## How to Play
1. Press **START** to begin the game.
2. Simon will play a sequence of colors and sounds.
3. Repeat the sequence by clicking the buttons in the correct order.
4. If you get it right, Simon will add another step to the sequence.
5. The game continues until you make a mistake.
